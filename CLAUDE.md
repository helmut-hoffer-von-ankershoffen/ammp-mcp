# CLAUDE.md — `ammp-mcp`

Pointer for Claude Code (and other Claude-flavoured agents) editing this repo.

## Read these first

1. **`AGENTS.md`** — operator playbook: architecture, conventions, quality bars, test layout, transports, commit identity. **Load-bearing.**
2. **The relevant module's `CLAUDE.md`** — per-domain guide for the module you're touching. Lives at `src/ammp_mcp/<module>/CLAUDE.md` (`mentor/`, `mentee/`, `playbook/`, `system/`, `backends/`).
3. **`CLI_REFERENCE.md`** — autogenerated from the Typer app. Regenerate via `tools/generate_cli_reference.py` after CLI changes.

## Claude-specific tips

- The repo follows the **Aignostics/python-sdk modulith pattern**: every domain folder has `_service.py` (logic) and `_cli.py` (Typer shell). Public API per module lives in that module's `__init__.py`; everything else is package-private (underscore-prefixed module names).
- **Subject-then-action CLI** (`ammp mentor list`, not `ammp list mentors`).
- **Five MCP tools** (`ListPlaybooks`, `GetPlaybook`, `SearchPlaybooks`, `AskMentor`, `EscalateToHuman`) are PascalCase on the wire — the function name *is* the AMMP operation name. SonarCloud's snake_case rule is suppressed in `sonar-project.properties` for these five.
- **Mentor backends** are pluggable. When extending, subclass `MentorBackend` in `backends/base.py`, register a new `kind` literal in `mentor/_models.py`, and wire it up in `backends/factory.py`.
- **The MCP server is stateless** by AMMP §6.1. Don't add per-mentee state to `ServerContext`. The hash-only audit log in `audit.py` is the only retention surface.
- **The `_load_one` function in `playbook/_service.py` is module-private** but referenced by `server.py` for single-playbook GET. Keep it underscored; don't promote.


## Don't

- Don't add new top-level files to `src/ammp_mcp/` — extend an existing domain or create a new domain folder.
- Don't write to `mentor.json` or `mentees.json` directly — go through the `mentor/_service.py` / `mentee/_service.py` helpers (they handle `ensure_ascii=False` and atomic-write semantics correctly).
- Don't bypass the audit log on the five tool handlers in `server.py`. Every mentee call logs hash-only.
- Don't drop the `personGeneration=allow_adult` requirement or weaken the privacy posture (no-retention, hash-only audit, no cross-compartment escalation) — these are advertised in `/.well-known/agent.json` and load-bearing per AMMP §3-§6.
